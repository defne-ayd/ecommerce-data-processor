# E-Commerce Data Processing & Filtering System

This project is a Python-based data processing script that simulates backend operations for an e-commerce platform. It handles reading, updating, and filtering structured data from raw text files.

## Key Features
* **File I/O & Data Management:** Reads and processes data from external files (`users.txt` and `products.txt`), and generates automated checkout reports (`transaction_summary.txt`).
* **Recursive Functions:** Implements recursive algorithms to batch-update product details (pricing and stock factors) across multiple target IDs.
* **Data Filtering:** Uses advanced list comprehensions to efficiently query and filter the dataset based on price ranges, stock availability, and keyword matching.
* **State Management:** Simulates a dynamic shopping cart system with conditional discount logic based on cart totals and specific item contents.

## Technologies
* Python (File I/O, Dictionaries, Recursion, List Comprehensions)
